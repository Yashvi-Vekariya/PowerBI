# ⚡ Electric Vehicle Sales Analytics Dashboard

A professional, data-driven dashboard built to analyze and visualize *electric vehicle (EV) sales* across India by state and manufacturer over time.  
This project helps monitor *penetration rates, track **growth trends* like *CAGR, and understand **market performance* across categories (2-Wheeler vs 4-Wheeler).

---

## 📊 Project Insights

Key business metrics analyzed and displayed in the dashboard:

- *Total EVs Sold*: 12,00,000+ electric vehicles
- *Top Selling States*: Maharashtra, Karnataka, Tamil Nadu
- *Leading Manufacturers*: Ola Electric, Tata Motors, Ather Energy
- *2-Wheeler Dominance*: 2-Wheelers contribute 70%+ of total EV sales
- *Penetration Rate*: 6.5% (National average)
- *Revenue Growth*: 📈 CAGR of 18% from 2021 to 2025
- *Quarterly Trends*: Highest sales recorded in Q4 across years
- *YoY Growth*: Consistent year-on-year growth of EV adoption

## 📂 Datasets Used

This project is powered by three main datasets:

---

### 1. *electric_vehicle_sales_by_state.csv*

| Column | Description |
|:------|:------------|
| date | The date on which the data was recorded. Format: DD-MMM-YY. (Monthly) |
| state | The name of the state where the sales data is recorded. |
| vehicle_category | Category of vehicle: 2-Wheeler or 4-Wheeler. |
| electric_vehicles_sold | Number of electric vehicles sold. |
| total_vehicles_sold | Total number of vehicles (electric + non-electric) sold. |

---

### 2. *electric_vehicle_sales_by_makers.csv*

| Column | Description |
|:------|:------------|
| date | The date on which the sales data was recorded. Format: DD-MMM-YY. |
| vehicle_category | Category of vehicle: 2-Wheeler or 4-Wheeler. |
| maker | Manufacturer or brand name. |
| electric_vehicles_sold | Number of electric vehicles sold by the maker. |

---

### 3. *dim_date.csv*

| Column | Description |
|:------|:------------|
| date | Specific date. Format: DD-MMM-YY. |
| fiscal_year | Fiscal year (April–March). |
| quarter | Fiscal quarter (Q1, Q2, Q3, Q4). |

---

## 🧠 Key Analytical Concepts

- *Fiscal Year*:  
  India follows a fiscal year from April 1st to March 31st.
